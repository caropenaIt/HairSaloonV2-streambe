## Project
- Web-app para crear, editar y borrar turnos y base de datos de peluqueros.
- CSS como hoja de estilos.
- React con Vite como framework de trabajo

## Commands
- npm install.
- npm run dev.

## Code style
- El código debe estar en español de forma fácil de leer y comprender.
- Hojas de CSS para cada componente.
- Nombres claros.
- Componentes: PascalCase.
- Variables: camelCase.
- Clases: camelCase.
- No usar `any`.
- No usar `!important`.
- No usar comando `npm run build`.
- Código lo más limpio posible.
- No modificar código legacy sin autorización.
- Uso de Hooks y Router.
- Base de datos en un archivo .json hasta que se ordene otro método


## Agent behavior
- Primero, planear el plan.
- Segundo, ejecutar en modo agente en cuanto se es solicitado.
- No hacer cambios importantes en base de datos y funciones importantes sin previa autorización.
